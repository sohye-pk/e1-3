# Mini NPU Simulator

## 1. 실행 방법

```bash
python main.py
```

`data.json`은 `main.py`와 동일한 디렉터리에 위치해야 합니다.

실행 후 모드를 선택합니다.

* `1`: 사용자 입력 (3×3)
* `2`: `data.json` 분석

## 2. 기능

### 모드 1 - 사용자 입력

* 3×3 필터 A, B와 패턴을 입력
* 각 필터의 MAC 점수 계산
* 두 점수를 비교하여 A / B / UNDECIDED 판정
* MAC 연산 시간 측정

### 모드 2 - data.json 분석

* `data.json`에서 5×5, 13×13, 25×25 필터와 패턴을 로드
* 패턴 키의 크기를 기준으로 해당 필터 선택
* 필터와 패턴의 크기 검증
* MAC 점수 비교 후 Cross / X / UNDECIDED 판정
* `expected`와 비교하여 PASS / FAIL 처리
* 실패 케이스의 식별자와 실패 사유 출력
* 크기별 MAC 연산 성능 측정

## 3. 구현 요약

### MAC 연산

패턴과 필터의 같은 위치에 있는 값을 곱한 뒤 모두 더하여 MAC 점수를 계산합니다.

```text
score += pattern[i][j] * filter[i][j]
```

외부 라이브러리 없이 중첩 반복문으로 직접 구현했습니다.

### 라벨 정규화

JSON의 서로 다른 라벨 표현을 프로그램 내부의 표준 라벨로 변환합니다.

* `+` → `Cross`
* `cross` → `Cross`
* `x` → `X`

PASS / FAIL 비교와 콘솔 출력은 `Cross`, `X` 표준 라벨을 기준으로 수행합니다.

### 점수 비교

두 MAC 점수의 차이가 `epsilon`보다 작은 경우 동점으로 처리합니다.

```text
abs(score_a - score_b) < 1e-9
```

동점인 경우 `UNDECIDED`로 판정합니다.

## 4. 결과 리포트

### 테스트 결과

`data.json` 모드 실행 시 전체 테스트 수, 통과 수, 실패 수를 출력합니다.

실패 케이스가 발생하면 케이스 식별자와 실패 사유를 함께 출력합니다.

```text
FAIL: size_13_1
원인: expected와 실제 판정 결과가 일치하지 않음
```

### 실패 원인 분석

FAIL 발생 시 다음 기준으로 원인을 분류합니다.

* 라벨 / 스키마 문제: JSON의 라벨 표현이나 데이터 구조가 예상 형식과 다른 경우
* 데이터 크기 문제: 패턴과 필터의 행 또는 열 크기가 일치하지 않는 경우
* 로직 문제: 필터 선택이나 MAC 계산 과정에 오류가 있는 경우
* 부동소수점 문제: 실수 계산의 미세한 오차로 점수 비교 결과가 달라지는 경우
* 비교 정책 문제: 두 점수의 차이가 `epsilon`보다 작아 `UNDECIDED`로 처리되는 경우

FAIL이 0개인 경우에도 모든 테스트의 `expected`와 실제 판정 결과가 일치했는지 확인하고, 라벨 정규화와 epsilon 기반 비교가 정상적으로 적용되었는지 함께 기록합니다.

### 시간 복잡도 분석

MAC 연산은 N×N 크기의 패턴과 필터를 같은 위치끼리 순회하며 곱하고 누적합니다.

바깥쪽 반복문이 N번 실행되고 안쪽 반복문도 N번 실행됩니다.

따라서 전체 MAC 연산 횟수는 `N × N = N²`입니다.

예를 들어 3×3은 9회, 5×5는 25회, 13×13은 169회, 25×25는 625회의 위치 연산을 수행합니다.

따라서 MAC 연산의 시간 복잡도는 **O(N²)**입니다.

실제 성능 측정에서는 각 크기의 MAC 연산을 최소 10회 반복하고 평균 실행 시간을 측정합니다.

측정 시간에는 입력, 출력, 파일 읽기 등의 I/O 시간을 포함하지 않고 MAC 연산 함수 호출 구간을 중심으로 측정합니다.

### 성능 측정 결과

| 크기    | 연산 횟수(N²) | 평균 시간(ms) |
| ----- | --------: | --------: |
| 3×3   |         9 |    실제 측정값 |
| 5×5   |        25 |    실제 측정값 |
| 13×13 |       169 |    실제 측정값 |
| 25×25 |       625 |    실제 측정값 |

실제 측정 결과를 통해 입력 크기 증가에 따른 연산 횟수와 실행 시간의 변화를 비교합니다.

## 5. 보너스 과제

### 패턴 생성기

사용자가 N을 입력하면 N×N 크기의 Cross와 X 패턴을 생성합니다.

생성된 패턴은 성능 분석 및 테스트에 재사용할 수 있도록 구현합니다.

### 시뮬레이터 최적화

기존 2차원 배열을 길이 N²의 1차원 배열로 변환하여 MAC 연산을 수행합니다.

동일한 입력과 반복 횟수를 사용하여 최적화 전후의 실행 시간을 비교합니다.

## 6. 개발 환경

* Python 3.8+
* Python 표준 라이브러리 사용
* 외부 라이브러리 사용 없음
